# NutriTrack — Calorie & Macro Tracker

A lightweight, responsive calorie and macronutrient tracking web application built with **pure vanilla HTML, CSS, and JavaScript**. 

No build tools, no frameworks, no Tailwind, no CSS variables, and no backend needed. All your data is stored locally in your web browser using `localStorage`.

---

## ✨ Features

- **Daily Calorie Dashboard**: Visual SVG progress ring tracking consumed calories, daily target, and remaining budget.
- **Macronutrient Tracking**: Real-time progress bars for Protein, Carbohydrates, and Fat with gram counts, percentages, and calorie contribution breakdowns.
- **Meal Categorization**: Log food across 4 categories: Breakfast, Lunch, Dinner, and Snacks, each with real-time totals.
- **Water Intake Tracker**: Visual glass counter (250 ml increments) with quick add/subtract buttons.
- **Food Library**: Preloaded with common whole foods, searchable, and lets you save your own custom food items.
- **Date Navigation**: Previous/Next day arrows, today jump button, and date picker to view or log entries across past or future days.
- **7-Day Weekly Trends**: HTML5 Canvas bar chart visualizing weekly calorie intake alongside daily target and adherence rates.
- **Data Export & Import**: Export all your data as a JSON file or restore from a previous backup.
- **Zero Dependencies**: 100% vanilla web technologies.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/aaronomokaro/calorie-tracker.git

# Open in browser
open index.html
```

Or open the file directly by double-clicking `index.html`.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic elements and SVG graphics.
- **CSS3**: Responsive flexbox and grid layouts, pure custom styles (no CSS variables, no utility frameworks).
- **JavaScript (ES6+)**: Modular vanilla JS with HTML5 Canvas API and `localStorage` persistence.
